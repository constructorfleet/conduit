# Architecture Decision Records

Long-lived architecture decisions belong in this directory.

ADRs are recorded here as `NNNN-kebab-case-title.md`, numbered in the order
they were decided. Read the ones that touch the area you are about to work in
before changing it, and say so explicitly when a change contradicts one rather
than silently overriding it.

The architecture these decisions produced is described in
[../architecture.md](../architecture.md), and repository-wide engineering rules
are in [../../AGENTS.md](../../AGENTS.md).

Implementation specs derived from an ADR live in [../specs/](../specs/). An ADR
records what was decided and why; a spec records what to build as a result.
